### 11.1. 결측값 처리

#### 식별/분류
- 표시 예시: `:`, `NaN`, `NA`, 빈 문자열 등.
- 유형: **MCAR**(완전무작위), **MAR**(조건부무작위), **NMAR**(비무작위).

#### 처리 방법
- **제거(Removal):** 결측률이 매우 낮거나(예: < **1%**) 분석 불필요 변수 제외. 관측치 제거 방식은 **Complete-case analysis**로, 결측률이 **10% 미만**일 때 고려.
- **대치(Imputation):**
  - **단순 대치:** 평균/중앙값/최빈값/특정값(0, min, max 등). (평균 대치는 분산 과소추정·편향 증가 가능)
  - **시계열 보간:** `pad`(전값), `bfill`(후값), 선형 보간 등.
  - **회귀 대치:** 결측 변수를 종속변수로 회귀 예측값으로 대치.
  - **확률적 회귀 대치:** 회귀 대치에 잡음 추가로 분산 과소추정 완화.
  - **다중 대치(MI/MICE):** 가상 데이터 다수 생성 후 평균/통합 추정.

```python
# 예시: pandas + scikit-learn
import pandas as pd
from sklearn.impute import SimpleImputer

df = pd.DataFrame({"x":[1,2,None,4], "y":[10,None,30,40]})

# 단순 대치 - 중앙값
imputer = SimpleImputer(strategy="median")
df[["x","y"]] = imputer.fit_transform(df[["x","y"]])

# 시계열 보간 (전방 채우기 → 후방 채우기)
df_ts = df.sort_index()
df_ts = df_ts.fillna(method="ffill").fillna(method="bfill")
````

### 11.2. 이상치 처리

#### 식별
- EDA/시각화: 분포 확인, **Box Plot**.
- 통계 기준:
  * Z-점수: 평균으로부터 ±**nσ**(일반적으로 n=3).
  * **중앙값·MAD:** 이상치에 강건(robust).
  * **IQR 기준:** Q1−**1.5×IQR** 미만, Q3+**1.5×IQR** 초과(분포 넓으면 3×IQR도 사용).

#### 처리 

- 제거(Trimming): 단순하지만 분산·편향 영향 가능.
- 값 수정: 상·하한 **winsorization**, 결측 전환 후 결측 대치 파이프라인 적용.

```python
import numpy as np

def iqr_clip(s, k=1.5):
    q1, q3 = s.quantile([0.25, 0.75])
    iqr = q3 - q1
    low, high = q1 - k*iqr, q3 + k*iqr
    return s.clip(lower=low, upper=high)

df["x_clipped"] = iqr_clip(df["x"], k=1.5)
```


### 11.3. 변수 구간화

#### 목적
- 연속형 → 범주형 변환으로 **해석성**·**안정성** 향상, 비선형 관계의 완화.

#### 기법
- 동일 폭(Equal Width):** 값 범위를 동일 간격으로 분할.
- 동일 빈도(Equal Frequency):** 관측치 수가 유사하도록 분할(`qcut`).
- 평활화(Smoothing):** 각 구간을 평균/중앙/경계값으로 대표.
- WOE/IV:** 로지스틱 맥락의 정보량 지표. 일반적 기준으로 **IV > 0.3**이면 강한 예측력.

```python
# 동일 빈도 구간화
df["age_bin"] = pd.qcut(df["x"], q=5, duplicates="drop")

# 더미 인코딩
df = pd.get_dummies(df, columns=["age_bin"], drop_first=True)
```


### 11.4. 데이터 표준화와 정규화 스케일링

**언제 필요한가?** 단위가 다른 변수가 혼재하거나 편차가 큰 경우, 특히 **거리 기반**(KNN, K-means)·**신경망**·**규제 회귀**에서 필수.

**표준화(Standardization)**

* 목표: 평균 **0**, 표준편차 **1**.
* 변환: ( z = \frac{X-\mu}{\sigma} )

**정규화(Normalization)**

* 목표: 범위 **[0,1]**.
* 변환: ( x' = \frac{x - x_{min}}{x_{max}-x_{min}} )

**RobustScaler**

* **중앙값(Q2)**, **IQR** 사용 → 이상치 영향 최소화.

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler

sc_std = StandardScaler()
sc_minmax = MinMaxScaler()
sc_robust = RobustScaler()

X_std = sc_std.fit_transform(df[["x","y"]])
X_minmax = sc_minmax.fit_transform(df[["x","y"]])
X_robust = sc_robust.fit_transform(df[["x","y"]])
```

### 모델 성능 향상을 위한 파생 변수 생성

**의의**

* **도메인 지식**을 반영해 신호를 강화, 해석 가능성↑.
* 예: 로그/제곱근 변환으로 분산 안정화, **전월 대비 증감률**, **사용자 활동 최근성(Recency)**, **비율/밀도** 변수 등.

**예시 아이디어**

* **집계형:** 사용자별 평균/최대/표준편차, 최근 N회 평균.
* **변화율:** ((x_t - x_{t-1}) / |x_{t-1}|)
* **상호작용:** (x_1 \times x_2), (x_1/x_2) (정규화 후 권장).
* **시간 파생:** 요일, 시간대, 분기, 공휴일 더미.
