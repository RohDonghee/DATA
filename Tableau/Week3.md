# 학습 내용 정리

## 20강: 파이와 도넛차트
```
■ 도넛차트
- 파이 차트 위에 임의의 축을 설정하여 새로운 차트 얹음 
  (1) '열'을 더블 클릭한 후에 0을 입력해서 임의의 축 생성한 후에 열에 0을 하나 더 복사해서 원 2개 생성
  (2) 중앙에 들어온 원의 크기 및 색상을 변경 (기존 필드 전부 삭제 후 하나의 필드만 추가)
  (3) 이중축 설정을 통해 원 결합
  (4) 서식 및 머리글 표시 제거를 통해 보기 좋게 표현
```


## 21강: 워드와 버블차트

```
■ 버블 차트
- 값을 원형 크기에 따라 표현하는 그래프
- '원' 그래프를 통해서 표현

■ 워드 클라우드
- 어떤 텍스트가 가장 많이 등장하는지 크기로 표현하는 그래프
- 측정값 테이블을 우클릭한 채로 '크기'에 Drop하여 '카운트'시킴 
```



## 22강: 이중축과 결합축


```
■ 이중 축 (Dual Axis)

* 하나의 뷰 안에서 두 개의 축을 개별적으로 사용하는 차트
* 각 축에 대해 마크(막대, 라인 등)를 독립적으로 적용 가능
* 마크 창이 필드별로 생성되어 색상이나 크기를 개별 수정 가능
* 서로 다른 척도를 가질 경우 '축 동기화'를 통해 기준 통일 필요

■ 결합 축 (Combined Axis)

* 하나의 축을 공유하여 여러 측정값을 표현하는 차트
* 측정값 중 가장 큰 범위를 가진 축을 기준으로 공유
* 모든 필드가 '측정값' 카드 내에서 관리되며 동일한 마크 유형 사용
* 기존 축 위로 필드를 드래그하여 초록색 이중 막대 표시가 나타날 때 생성

■ 핵심 차이점 요약

* 이중 축: 축 2개 사용, 마크 개별 제어 가능 (예: 막대와 라인 혼합)
* 결합 축: 축 1개 공유, 동일한 마크 유형 사용 (예: 라인과 라인 비교)

혹시 이 내용을 바탕으로 실제 태블로에서 구현하는 단계별 순서도 정리해 드릴까요?



## 23강: 분산형 차트

- 파라미터 간의 상관관계 파악
- 추세선을 활용하여 주로 표현
```


```js
강의 영상과 달리, 우리 파일에는 '제조 업체' 필드가 없습니다. 필요한 경우, 계산된 필드를 이용해 'SPLIT([제품 이름], ' ', 1)'를 '제조 업체'로 정의하시고 세부 정보에 놓아주세요.
```



## 24강: 히스토그램

```
■ 히스토그램 (Histogram)

- 데이터의 분포 형태를 표시하는 차트
- 연속형 측정값을 일정 범위의 '구간 차원'으로 그룹화하여 빈도를 막대 형태로 표현
- 차원 필드 없이 측정값만으로 그래프를 그릴 때 주로 사용

■ 구간 차원 (Bin)

- 일정한 크기의 포켓을 만들어 그 안에 값을 담아 표현하는 도구
- 생성 시 데이터 패널의 차원 영역에 새로운 필드로 나타남

■ 히스토그램 생성 방법
- 수동 생성: 측정값 우클릭 > 만들기 > 구간 차원 설정 > 열 선반에 배치(연속형 변환) > 행 선반에 측정값 배치(카운트로 변경)
- 자동 생성: 측정값을 열 선반에 올린 후 우측 '표현 방식'에서 히스토그램 아이콘 클릭
- 자동 생성 시 태블로 내부 동작: 뷰 변환, 구간 차원 자동 생성 및 배치, 측정값을 합계에서 카운트로 변경

■ 기타 
- 로그 배율: 데이터의 최솟값과 최댓값 차이가 극단적일 때 축 편집에서 '로그'를 활성화하여 뷰 조정 가능
- 색상 구분: 차원 필드(예: 범주)를 색상 마크로 드래그하여 항목별 분포 확인 가능
- 카운트 고유: 중복 값을 제외하고 빈도를 계산하고 싶을 때 측정값 집계 방식을 '카운트(고유)'로 선택 가능
```

## 27강: 간트차트
```
■ 간트 차트 (Gantt Chart)
- 시간 경과에 따른 기간이나 작업의 일정을 시각화하는 차트
- 주로 프로젝트 관리나 배송 기간 분석 등에 활용

■ 주요 생성 단계
- 축 설정: 날짜 필드(예: 배송 날짜)를 열 선반에 배치
- 항목 설정: 분석할 차원(예: 제품 범주)을 행 선반에 배치
- 기간 계산: DATEDIFF 함수를 사용하여 시작일과 종료일 사이의 차이(배송 기간)를 계산
- 마크 적용: 계산된 기간 필드를 마크 카드의 '크기'에 넣고, 마크 유형을 '간트 차트'로 선택

■ 핵심 팁
- 집계 방식 변경: 기간 데이터가 합계로 표시되지 않도록 측정값을 '평균' 등으로 변경 필요 
- 시각적 구분: '배송 형태' 등의 필드를 색상 마크에 넣어 항목별로 구분 
- 필터 활용: 특정 항목(예: 고객 이름)을 필터로 설정하여 데이터 가독성 향상 
- 분석-계산된 필드 만들기를 통해서 파생 필드 만들 수 있음 (ex. 날짜 차이의 경우, DATEDIFF)
```



## 28강: 필터
```
■ 필터 기능 (Filter)
- 데이터 분석의 필수 요소로, 뷰의 구성뿐만 아니라 쿼리 속도와 성능 최적화에 중요한 역할 수행
- 태블로는 추출 → 데이터 원본 → 컨텍스트 → 차원 → 측정값 필터 순으로 우선순위를 가지고 동작

■ 추출 필터 (Extract Filter)
- 데이터 원본에서 로컬로 데이터를 가져올 때 가장 먼저 적용되는 필터
- 필요한 데이터만 따로 저장하여 전체적인 작업 속도를 향상시킬 때 사용

■ 데이터 원본 필터 (Data Source Filter)

- 워크스페이스로 데이터를 불러올 때 특정 조건의 데이터만 포함되도록 설정
- 작업을 시작하기 전 원천적으로 불필요한 데이터를 제외하는 단계

■ 컨텍스트 필터 (Context Filter)
- 일반 필터보다 우선순위를 갖는 상위 필터로, 필터 간의 종속 관계를 형성
- 특정 범주 내에서의 상위 N개 데이터를 추출할 때처럼 기준이 되는 필터링이 필요할 때 사용
- 적용 시 필터 선반에서 회색으로 표시되며 최상단에 고정됨

■ 차원 필터 (Dimension Filter)
- 목록에서 선택: 리스트에서 직접 항목을 선택하거나 특정 항목만 제외
- 와일드카드: 특정 단어를 포함하거나 시작/끝나는 문자열을 기준으로 필터링
- 조건: 측정값의 범위를 기준으로 차원 데이터를 필터링 (예: 매출액 1,000만 원 이상인 제품군)
- 상위: 특정 측정값을 기준으로 상위 또는 하위 N개의 데이터만 추출
```



## 29강: 그룹
```
■ 그룹 (Group)
- 수동으로 데이터 항목들을 묶어 기존 원본에 없는 사용자 지정 카테고리를 만드는 기능
- 차원에 있는 항목들을 여러 그룹으로 묶어 데이터를 단순화하거나 분석 목적에 맞게 재구성 가능

■ 그룹 생성 방법
- 뷰에서 직접 생성: 차트에서 그룹화할 데이터들을 드래그하여 선택한 후, 마우스 우클릭하여 '그룹' 선택
- 데이터 패널에서 생성: 필드 위에서 우클릭 > 만들기 > 그룹 선택 후 설정 화면에서 항목별로 묶기
- 기타 포함 기능: 특정 그룹 외 나머지 항목들을 하나로 묶어 '기타' 그룹으로 자동 생성 가능

■ 주요 특징
- 필드 생성: 그룹을 만들면 데이터 패널에 클립 모양의 아이콘이 붙은 새 필드가 생성됨
- 시각화 활용: 생성된 그룹 필드를 마크 카드의 색상에 넣어 구분하거나, 행/열 선반에 놓아 기준 축으로 사용
- 가시성 개선: 항목이 너무 많은 경우 그룹화된 필드를 사용하고, '기타' 항목을 필터링하여 주요 그룹 간의 차이점을 명확히 파악 가능
```
