# 학습 내용 정리

## 58. 집합값 변경 [동작 - 집합 값 변경]
```
- 대시보드 동작에서 '집합 값 변경'을 설정하여 사용자의 클릭에 따라 집합 멤버를 동적으로 업데이트 가능
- 특정 데이터 포인트를 클릭했을 때 해당 항목을 집합에 포함하거나 제외함으로써 시각적 상호작용(하이라이트, 필터링 등) 구현
- 선택을 해제했을 때 모든 값을 집합에 유지하거나 제거하는 등의 결과값 제어 옵션 활용 가능
```


## 59강. 스토리패널
```
- 하단 바의 '새 스토리' 아이콘을 클릭하여 생성하며, 여러 워크시트와 대시보드를 순차적인 이야기 흐름으로 구성
- 좌측 '스토리' 패널에서 스토리 포인트(장면)를 추가하고 배치하며, 레이아웃(캡션, 번호표 등)을 설정 가능
- '워크시트/대시보드' 목록에서 원하는 개체를 드래그하여 스토리 포인트에 삽입
```



## 60. 스토리
```
- 각 스토리 포인트는 특정 데이터의 상태(필터, 선택 등)를 독립적으로 저장하므로, 시청자에게 보여주고 싶은 통찰을 장면별로 고정 가능
- 캡션 박스에 핵심 메시지를 요약하여 기재함으로써 데이터가 말하고자 하는 바를 명확히 전달
- 단순히 차트를 나열하는 것이 아니라, 현상 파악에서 원인 분석으로 이어지는 논리적 흐름(Narrative) 구성이 중요
```


## 61. 대시보드 탐색
```
- 대시보드 개체 중 '탐색'을 활용하여 서로 다른 대시보드나 시트 간의 이동을 버튼으로 구현
- 단순한 시트 탭 이동보다 사용자 경험(UX) 측면에서 직관적이며, 프레젠테이션 형태의 대시보드 구성에 유리
- 탐색 버튼의 텍스트, 글꼴, 색상 및 이미지 단추 활용 여부를 편집 가능
```



## 62. 태블로 단추
```
- '탐색' 단추와 '개체 표시/숨기기' 단추를 통해 대시보드 공간을 효율적으로 활용
- 플로팅(부동) 컨테이너와 연동된 단추를 만들어, 평소에는 필터나 범례를 숨겼다가 필요할 때만 나타나게 설정 가능
- 단추의 스타일(이미지/텍스트)을 대시보드 디자인 콘셉트에 맞춰 커스터마이징하여 완성도 제어
```



## 63. 막대그래프 드릴다운
```
- 집합 동작(Set Action)을 활용하여 특정 막대를 클릭하면 그 하위 계층이 펼쳐지는 '드릴다운' 효과 구현
- 계산된 필드를 사용하여 [선택한 집합 내에 있으면 하위 차원 표시, 아니면 상위 차원 유지] 로직 적용
- 대시보드 내에서 시각적 공간을 적게 차지하면서도 상세 데이터를 탐색하기에 적합
```


## 64. 트리맵 드릴다운
```
- 상위 범주를 클릭했을 때 해당 영역 안에서 하위 항목들의 비중과 상세 내역이 나타나도록 구성
- 트리맵의 시각적 계층 구조를 집합 동작과 결합하여, 전체에서 세부 항목으로 좁혀가는 분석 방식 제공
- 집합에 포함된 멤버만 색상이나 레이블을 다르게 표현하여 가독성 증대
```

## 65. 파이 차트 드릴다운
```
- 파이 차트의 특정 조각을 선택하면 해당 항목의 구성 요소로 차트가 변경되거나 세부 정보가 나타나도록 설정
- 복잡한 비중 데이터를 한눈에 보여주고, 사용자가 궁금한 부분만 깊이 있게 탐색할 수 있도록 유도
- 파이 차트의 가독성 문제를 드릴다운 상호작용을 통해 보완 가능
```


## 66. 지도 드릴다운
```
- 지도상의 특정 지역(예: 시/도)을 클릭하면 해당 지역 내의 하위 행정구역(예: 시/군/구)이 지도에 표시되도록 구현
- 지리적 역할을 가진 필드와 집합 동작을 연계하여 공간적 분석의 깊이를 조절
- 맵 레이어 혹은 계산된 필드를 활용해 드릴다운 시 지도의 확대/축소 및 상세도 전환 효과 부여
```
