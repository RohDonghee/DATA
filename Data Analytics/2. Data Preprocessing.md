
# 1. Summary Statistics

## ■ Definition
- Numerical measures summarizing data properties  
- Covers frequency, location, spread  
- Efficient to compute (single pass possible)

## ■ For Categorical Attributes
### □ Frequency
- Number of occurrences of each category  

### □ Mode
- Most frequent category value  

## ■ For Continuous Attributes
### □ Percentiles
- p-th percentile = value where p% of observations fall below it  
- 50th percentile = median  

### □ Measures of Location
- Mean: average value  
- Median: 50th percentile  
- More robust to outliers  

### □ Measures of Spread
- Range = max – min  
- Variance / Standard deviation  

---

# 2. Visualization

## ■ Definition
- Converting data to visual formats for pattern analysis  
- Uses human ability to detect patterns, clusters, anomalies  

## ■ Representation
- Objects as points, lines, shapes, colors  
- Attributes mapped to position, size, or color  

## ■ Visualization Techniques
### □ Histogram
- Distribution of single numeric variable  
- Sensitive to bin width  

### □ Two-Dimensional Histogram
- Joint distribution of two numeric variables  

### □ Box Plot
- Median, quartiles, IQR, outliers  

### □ Scatter Plot
- Relationship between attributes  
- Additional encoding via size, color, shape  

### □ Contour Plot
- Continuous values on grid  
- Contour lines represent equal magnitude  

### □ Bar Chart
- Categorical variable visualization  

### □ Log-Scale Rescaling
- Useful for data near zero or spanning wide ranges  

### □ Line Chart
- Time-series visualization  

### □ Parallel Coordinates
- High-dimensional visualization  
- Each object = line across attribute axes  

### □ Heatmap
- Color-coded matrix of values or correlations  

---

# 3. Pitfalls of Data Visualization

## ■ Truncated Axis
- Cutting y-axis exaggerates differences  

## ■ Area Sized by One Dimension
- Misleading scaling  

## ■ Confusing Correlation and Causation  
- Visual proximity can imply false causality  

## ■ Dual Axes
- Two scales can mislead correlations  

## ■ Limited Scope (Cherry Picking)
- Selecting only favorable data points introduces bias  

## ■ Absolute vs Relative Interpretation
- Relative values often more meaningful

# 4. Classification I  
(Introduction to Classification)

## ■ Definition
- Predict categorical class labels using data  
- Model outputs class or probability of class  

## ■ Types of Classification
### □ Binary Classification
- Two classes (e.g., fraud/no fraud)

### □ Multi-class Classification
- More than two classes  

### □ Ordered Classification
- Classes have natural order  

## ■ General Framework
- Input: feature vector X

## ■ Key Concepts
### □ Training vs Testing
- Train: learn model parameters  
- Test: evaluate generalization  

### □ Decision Boundary
- Separates classes in feature space

- Model too complex, memorizes noise

- Model too simple, misses patterns

# 5. Classification II  
(Logistic Regression, Naïve Bayes, Bayes Theorem)  
:contentReference[oaicite:1]{index=1}

## ■ Probability Basics
### □ Independent Events
- P(A and B) = P(A)·P(B)

### □ Dependent Events
- Occurrence of one affects probability of the other  

### □ Conditional Probability
- P(A | B) = P(A and B) / P(B)

### □ Bayes Theorem
- P(A|B) = [P(B|A)·P(A)] / P(B)

---

## ■ Logistic Regression

### □ Goal
- Predict probability of binary outcome (0/1)

### □ Model
log(p / (1 - p)) = β₀ + β₁X  
- Uses log-odds transformation  
- Probability obtained via sigmoid:

p = 1 / (1 + e^(-z))

### □ Interpretation
- β > 0 → X increases probability of class=1  
- Uses z-statistic, p-values for inference  

### □ Multi-variable Logistic Regression
log(p / (1 - p)) = β₀ + β₁x₁ + … + βₚxₚ

---

## ■ Naïve Bayes Classifier

### □ Idea
- Use Bayes theorem + conditional independence assumption  
- Classify X into class y such that:

y = argmax P(y) Π P(xᵢ|y)

### □ For Categorical Attributes
P(xᵢ = c | y) computed by frequency

### □ For Continuous Attributes
Often assume Gaussian distribution  

### □ Strengths
- Fast, simple, effective  
- Performs well even with weak independence assumption

# 6. Classification III  
(Model Evaluation, Confusion Matrix, ROC, AUC)  
:contentReference[oaicite:2]{index=2}

## ■ Need for Performance Evaluation
- Accuracy alone insufficient (especially with imbalance)

---

## ■ Confusion Matrix

| Actual / Predicted | Yes | No |
|--------------------|-----|----|
| Yes                | TP  | FN |
| No                 | FP  | TN |

- TP = true positive  
- FN = false negative  
- FP = false positive  
- TN = true negative  

---

## ■ Performance Metrics

### □ Accuracy  
(TP + TN) / (TP + TN + FP + FN)

### □ Precision  
TP / (TP + FP)

### □ Recall (Sensitivity, TPR)  
TP / (TP + FN)

### □ Specificity (TNR)  
TN / (TN + FP)

### □ F1 Score  
2 · (Precision · Recall) / (Precision + Recall)

---

## ■ Class Imbalance
- Accuracy misleading when class distribution is skewed  
- Rare class detection usually more important  

---

## ■ Threshold Setting
- Many models output probabilities  
- Cutoff determines positive/negative classification  
- Changing threshold → tradeoff between TPR and FPR  

---

## ■ ROC Curve
- Plot: TPR vs FPR at various thresholds  
- Illustrates tradeoff between sensitivity and false alarms  

### □ AUC (Area Under Curve)
- 1.0 = perfect  
- 0.5 = random guess  
- Cutoff-invariant metric  

---

## ■ Asymmetric Misclassification Costs
- Cost(FN) vs Cost(FP) may differ significantly  
- Example: fire detection, fraud detection
