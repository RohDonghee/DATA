# 1. Summary Statistics

## ■ Definition
- Numerical measures summarizing data properties  
- Covers frequency, location, spread  
- Efficient to compute (single pass possible)

## ■ For Categorical Attributes
### □ Frequency
- Number of occurrences of each category  

### □ Mode
- Most frequent category value  

## ■ For Continuous Attributes
### □ Percentiles
- p-th percentile = value where p% of observations fall below it  
- 50th percentile = median  

### □ Measures of Location
- Mean: average value  
- Median: 50th percentile  
- Median more robust to outliers  

### □ Measures of Spread
- Range = max − min  
- Variance / Standard Deviation: common dispersion measures

# 2. Visualization

## ■ Definition
- Converting data into visual formats for pattern analysis  
- Leverages human ability to detect patterns, trends, outliers  

## ■ Representation
- Objects shown as points, lines, shapes, colors  
- Attribute values mapped to position, color, size  

## ■ Visualization Techniques
### □ Histogram
- Shows distribution of a single variable  
- Dependent on number of bins  

### □ Two-Dimensional Histogram
- Joint distribution of two variables  

### □ Box Plot
- Shows median, quartiles, range, outliers  

### □ Scatter Plot
- Shows relationships between attributes  
- Additional attributes encoded by marker size/shape/color  

### □ Contour Plot
- Visualizes continuous values on a spatial grid  
- Regions with similar values connected by contour lines  

### □ Bar Chart
- For categorical variables  
- Can display aggregated statistics per category  

### □ Log-Scale Rescaling
- Useful when values are near zero  
- Improves interpretability  

### □ Line Chart
- For time-series data  
- Detects trends and patterns  

### □ Parallel Coordinates
- Visualizes high-dimensional data  
- Each object represented as a line across parallel axes  

### □ Heatmap
- Color-based visualization of magnitudes or correlations  

---

# 3. Pitfalls of Data Visualization

## ■ Truncated Axis
- Y-axis not starting at zero exaggerates differences  

## ■ Area Sized by Single Dimension
- Misleading scaling inflates significance  

## ■ Confusing Correlation and Causation
- Visuals may imply false causal relationships  

## ■ Dual Axes
- Two scales may falsely imply correlation  

## ■ Limited Scope (Cherry Picking)
- Selectively displaying favorable data creates bias  

## ■ Seeing Only Absolute Values
- Relative comparisons required for fairness
