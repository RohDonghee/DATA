# 1. Data
Collection of data objects and attributes   

## 1-1 Object
A collection of attributes

## 1-2 Attribute
Property or characteristic of an object 

### ■ Discrete and Continuous Attributes
#### □ Discrete Attribute
  - Has only a finite or countably infinite set of values
  - Often represented as integer variables
  - Binary attributes are a special case of discrete attributes
  - Ex) Zip codes, Car numbers, etc…
#### □ Continuous Attribute
  - Has real numbers as attribute values
  - Practically, real values can only be measured and represented using a finites number of digits
  - Ex) Temperature, height, we

### ■ Important Characteristics of Data
#### □ Dimensionality
  - Dimension : **Number of attributes**
  - High dimensional data brings a number of challenges
#### □ Sparsity
  - Only presence counts
  - Ex) Only small number of ‘1’ and most are ‘0’
    - Bag-of-word(BoW) : Matching Process (Non-zero attribute values are important)
#### □ Resolution
  - Patterns depend on the scale
#### □ Size
  - Type of analysis may depend on size of data
