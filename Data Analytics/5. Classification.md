

# 1. Classification I  
(Fundamentals of Classification)

## ■ Definition
- Predict categorical class labels based on input features  
- Output may be class label or probability of each class  

## ■ Types of Classification
### □ Binary Classification
- Two classes (e.g., fraud / no fraud)

### □ Multi-class Classification
- More than two classes

### □ Ordered Classification
- Classes have natural ordering

## ■ General Classification Framework
- Input: feature vector X  
- Output: predicted label y or probability P(Y|X)  
- Goal: find function f(X) that best predicts Y

## ■ Training vs Testing
- Training set: used to learn model parameters  
- Test set: used to evaluate generalization ability  
- Important to avoid data leakage

## ■ Decision Boundary
- Surface that separates class regions in feature space  
- Depends on model: linear, nonlinear, piecewise, etc.

## ■ Overfitting vs Underfitting
### □ Overfitting
- Model too complex  
- Fits noise, performs poorly on unseen data

### □ Underfitting
- Model too simple  
- Misses underlying patterns in data

# 2. Classification II  
(Logistic Regression, Bayes Theorem, Naïve Bayes)

---

## 2.1 Probability Foundations

## ■ Independent Events
- P(A and B) = P(A) * P(B)  
- Occurrence of one does not affect the other

## ■ Dependent Events
- Occurrence of one affects the probability of the other  
- Example: gender vs height distribution

## ■ Conditional Probability
- Probability of A given B:  
  P(A|B) = P(A ∩ B) / P(B)

## ■ Bayes Theorem
- Posterior = (Likelihood × Prior) / Evidence  
- P(A|B) = [P(B|A) * P(A)] / P(B)
- In ML:
  - A = hypothesis  
  - B = observed data

---

## 2.2 Logistic Regression

## ■ Purpose
- Model probability of binary outcome  
- Output in [0, 1]  
- Avoids negative or >1 predictions of linear regression

## ■ Logistic Model
log(p / (1 - p)) = β₀ + β₁X  
- Left-hand side = log-odds  
- Sigmoid restores probability:

p = 1 / (1 + e^(-z))

## ■ Interpretation
- β > 0 → X increases probability of positive class  
- Coefficient significance measured via standard errors, z-statistics, p-values  
- Null hypothesis: βᵢ = 0

## ■ Multi-variable Extension
log(p / (1 - p)) = β₀ + β₁x₁ + … + βₚxₚ

---

## 2.3 Naïve Bayes Classifier

## ■ Idea
- Solve classification using probability distributions  
- Strong assumption: features are conditionally independent given class

## ■ Naïve Bayes Formula
P(Y = y | X) ∝ P(Y = y) · Π P(Xᵢ | Y = y)

## ■ Estimation
### □ Prior Probability
- P(y) = fraction of instances with class y

### □ Categorical Attributes
- P(Xᵢ = c | y) = (# instances with value c & class y) / (# instances of class y)

### □ Continuous Attributes
- Often modeled via Gaussian:
  P(X|y) = Normal(mean_y, variance_y)

## ■ Decision Rule
- Choose class y that maximizes posterior probability

# 3. Classification III  
(Model Evaluation, Confusion Matrix, ROC, AUC)

---

## 3.1 Performance Evaluation

## ■ Need for Evaluation
- Classification quality varies  
- Raw accuracy may be misleading (especially under imbalance)

---

## 3.2 Confusion Matrix

| Actual / Predicted | Yes | No |
|--------------------|-----|----|
| Yes                | TP  | FN |
| No                 | FP  | TN |

### □ Definitions
- TP: correctly predicted positive  
- TN: correctly predicted negative  
- FP: predicted positive but actually negative  
- FN: predicted negative but actually positive  

---

## 3.3 Common Metrics

### □ Accuracy  
(TP + TN) / (TP + TN + FP + FN)

### □ Precision  
TP / (TP + FP)

### □ Recall (Sensitivity, TPR)  
TP / (TP + FN)

### □ Specificity (TNR)  
TN / (TN + FP)

### □ F1 Score  
2 × (Precision × Recall) / (Precision + Recall)

---

## 3.4 Class Imbalance Issue
- Many domains have rare positive class  
  - Fraud detection  
  - Medical diagnosis  
  - Defect detection  
- Accuracy becomes meaningless  
- Need Recall, Precision, F1, ROC/AUC

---

## 3.5 Cutoff Thresholds
- Classifiers output continuous probability  
- Must choose cutoff (e.g., 0.5) for final prediction  
- Different cutoff → different TPR/FPR tradeoff

---

## 3.6 ROC Curve
- Plot TPR (y-axis) vs FPR (x-axis) across thresholds  
- Shows tradeoff between detection rate and false alarms  
- Steeper curve → better classifier

### □ Ideal ROC
- Passes near (0,1)

### □ Random Guess
- Diagonal line (AUC = 0.5)

---

## 3.7 AUC (Area Under the Curve)
- AUC = probability classifier ranks random positive higher than random negative  
- 1.0 = perfect  
- 0.5 = random  
- Cutoff-independent metric  
- Useful for comparing models

---

## 3.8 Asymmetric Misclassification Costs
- FN cost may be far higher than FP (e.g., fire detection, disease screening)  
- Threshold tuning required  
- Sometimes use cost-sensitive learning
