## 4.1 Linear Regression

### 4.1.1 Multiple Linear Regression

- **Basic Idea**
  - Assume a **linear relationship** between a continuous response variable \(y\) and **multiple predictors** \(x_1, x_2, \dots, x_p\).
  - We approximate the true relationship by a linear function:
    \[
      y \approx \hat{y} = \alpha + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_p x_p
    \]

- **Terminology**
  - **Response variable (y)**  
    - Also called **dependent variable**, **target**, or **output**.  
    - This is what we want to **predict or explain**.
  - **Predictors (xᵢ)**  
    - Also called **independent variables**, **features**, or **explanatory variables**.  
    - These are the inputs we use to explain variation in \(y\).

- **Interpretation of Coefficients**
  - \(\beta_j\) represents the **change in the mean of y** when \(x_j\) increases by 1 unit,  
    **holding all other predictors constant**.
  - Example: If \(\beta_2 = 3\), then increasing \(x_2\) by 1 (with others fixed) is associated with an average increase of 3 units in \(y\).

- **Main Assumptions (Conceptual)**
  - **Linearity**: relationship between predictors and response is approximately linear.
  - **Additivity**: effects of different predictors add together.
  - **Other assumptions** (for inference): e.g., errors are roughly normal with constant variance and independent.

---

### 4.1.2 Explanatory vs Predictive Regression

#### (a) Explanatory Regression

- **Goal**
  - Understand **how** variables are related:
    - Which predictors are important?
    - What is the **direction** (positive/negative) and **strength** of each effect?
  - Focus is on **interpretation** and **causal insight** (if design allows).

- **Typical Evaluation Tools**
  - **\(R^2\)**: proportion of variance in \(y\) explained by the model.
  - **Residual analysis**:
    - Check if residuals look random → model assumptions plausible.
    - Look for patterns, nonlinearity, heteroskedasticity, outliers.
  - **p-values, confidence intervals**:
    - Test whether each coefficient is significantly different from zero.
    - Decide which predictors seem statistically meaningful.

- **Applications**
  - Scientific research, economics, social sciences, medicine:
    - e.g., “How does smoking affect blood pressure?”,  
      “Which factors drive house prices?”

---

#### (b) Predictive Regression

- **Goal**
  - Maximize **prediction accuracy** (e.g., on future or unseen data).
  - Less emphasis on interpreting individual coefficients; more on **overall performance**.

- **Typical Evaluation Tools**
  - **MSE, RMSE, MAE, etc. on test data**:
    - Measure errors between true values and predictions.
    - Lower error → better predictive performance.
  - Cross-validation:
    - Repeatedly split data into train/validation sets to get reliable performance estimates.

- **Applications**
  - Forecasting, data mining, recommendation systems:
    - e.g., predicting sales next month, predicting a user’s rating for a movie, etc.

- **Key Difference**
  - Explanatory: “Why does y change?”  
  - Predictive: “How well can we predict y?”

## 4.2 Linear Regression Example

### 4.2.1 Example Description

- **Dataset**
  - 33 adult women.
  - Two continuous variables:
    - Age (x)
    - Systolic blood pressure, SBP (y)

- **Objective**
  - Model a **linear relationship** between Age and SBP.
  - Use Age to **predict** or understand variation in SBP.

- **Visualization**
  - We typically start with a **scatterplot** of Age vs SBP.
  - If the points roughly follow an upward sloping line, a linear model may be reasonable.

---

### 4.2.2 True Value, Predicted Value, Residual

- **Notation**
  - True value: \(y\)  
  - Predicted value: \(\hat{y}\)  
  - Residual (error): \(\varepsilon = y - \hat{y}\)

- **Relationship**
  - True y = Predicted y + Residual  
    \[
      y = \hat{y} + \varepsilon
    \]
  - Residual captures what the model **could not explain**.

- **Interpretation**
  - If \(\varepsilon > 0\): model **underestimates** the true value.
  - If \(\varepsilon < 0\): model **overestimates** the true value.
  - Good models have residuals that look like **random noise**, not patterns.

---

### 4.2.3 Linear Regression with Two Inputs

- **Model**
  - \[
      y = \beta_0 + \beta_1 x_1 + \beta_2 x_2
    \]
- **Geometric View**
  - In 3D space (x₁, x₂, y), the regression model is a **plane**.
  - True data points are scattered around this plane.
  - Residuals are the **vertical distances** from each point to the plane.

- **Intuition**
  - The regression tries to position the plane so that points lie **as close as possible** on average.
  - “Close” is measured in terms of **squared residuals** (see OLS below).

---

## 4.3 Linear Model

### 4.3.1 Linear Model Definition

- **Functional Form**
  - \[
      f(x) = \beta_0 + \beta_1 x_1 + \dots + \beta_p x_p
    \]
  - This is the **prediction function** for given input vector \(x\).

- **Vector Form**
  - Let \(x = (1, x_1, \dots, x_p)^\top\), \(\beta = (\beta_0, \beta_1, \dots, \beta_p)^\top\).  
  - Then:
    \[
      f(x) = \beta^\top x
    \]
  - This notation is compact and convenient for matrix algebra.

- **Residual**
  - For a given observation:
    \[
      \varepsilon = y - f(x)
    \]
  - The collection of residuals for all observations reflects how well the model fits the data overall.

---

## 4.4 Training a Linear Regression Model

### 4.4.1 Training Objective

- **Goal**
  - Use the training dataset:
    \[
      D = \{(x_1, y_1), \dots, (x_n, y_n)\}
    \]
  - to find the **best coefficients** \(\beta\).

- **“Best” According to What?**
  - We choose \(\beta\) that minimizes a certain measure of error, usually **sum of squared errors (SSE)**.

---

### 4.4.2 Ordinary Least Squares (OLS)

- **SSE (Sum of Squared Errors)**
  - \[
      SSE = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
    \]
  - Each residual is squared so that:
    - Positive and negative errors don’t cancel.
    - Larger errors are penalized more heavily.

- **OLS Estimator**
  - Choose \(\beta\) to minimize SSE.
  - For a single predictor:
    - \[
        \beta_1 = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}
      \]
    - \[
        \beta_0 = \bar{y} - \beta_1 \bar{x}
      \]
  - In multiple regression, there is a matrix formula \(\hat{\beta} = (X^\top X)^{-1} X^\top y\) (not required to memorize, but useful to know).

- **Intuition**
  - OLS finds the line/plane that makes the **overall squared vertical distance** from points to the line as small as possible.
  - It balances over- and under-predictions across all data points.

## 4.5 Regression Performance Evaluation

### 4.5.1 Training / Test Split

- **Training Set**
  - Used to **fit** the model (estimate \(\beta\)).

- **Test Set**
  - Used only to **evaluate** how well the model generalizes to unseen data.
  - Never touch the test set until model selection/tuning is complete.

- **Why Split?**
  - If you evaluate on the same data used for training, you may underestimate the true error (overly optimistic).
  - Test performance gives a more realistic estimate of **future performance**.

---

### 4.5.2 Types of Errors

- **Training Error**
  - Error computed on the **training data**.
  - Usually smaller because the model was optimized on this data.

- **Test Error**
  - Error computed on **test data**.
  - Better reflects performance on unseen data.

- **Generalization Error**
  - Theoretical concept: expected error on **new samples** from the same population.
  - In practice, we approximate it using the test error (or cross-validation).

---

### 4.5.3 Error Metrics

Let \(e_i = y_i - \hat{y}_i\) be the residual for observation i.

- **MSE (Mean Squared Error)**
  - \[
      MSE = \frac{1}{n} \sum_{i=1}^n e_i^2
    \]
  - Penalizes larger errors more strongly due to squaring.

- **RMSE (Root Mean Squared Error)**
  - \[
      RMSE = \sqrt{MSE}
    \]
  - Same units as y, easier to interpret (e.g., “on average, we are off by about 5 units”).

- **MAE (Mean Absolute Error)**
  - \[
      MAE = \frac{1}{n} \sum_{i=1}^n |e_i|
    \]
  - More robust to outliers than MSE because errors are not squared.

- **MAPE (Mean Absolute Percentage Error)**
  - \[
      MAPE = \frac{100}{n} \sum_{i=1}^n \left| \frac{e_i}{y_i} \right|
    \]
  - Expresses the error as a **percentage** of the true value.
  - Useful when scale of y varies, but problematic if some \(y_i\) are close to 0.

---

### 4.5.4 Goodness of Fit (R²)

- **Decomposition**
  - Total variability in y:
    - \(SST\) (Total Sum of Squares) = variability of \(y_i\) around \(\bar{y}\).
  - Explained variability:
    - \(SSR\) (Regression Sum of Squares) = variability explained by the model.
  - Unexplained variability:
    - \(SSE\) (Error Sum of Squares) = variability left in the residuals.
  - Relationship:
    - \(SST = SSR + SSE\).

- **R² Definition**
  - \[
      R^2 = 1 - \frac{SSE}{SST}
    \]
  - Measures the **proportion of variance** in y explained by the model.

- **Interpretation**
  - \(R^2 = 0\): model explains **none** of the variability (same as using the mean).
  - \(R^2 = 1\): model explains **all** variability (perfect fit on training data).
  - Higher \(R^2\) generally indicates a better fit, but:
    - It always increases (or stays the same) when you add more predictors, even if they are useless.
    - For predictive tasks, you must also consider test error, not just training \(R^2\).

---

### 4.5.5 Model Complexity

- **More Complex ≠ Always Better**
  - Adding more predictors or polynomial terms can reduce training error and increase \(R^2\).
  - But beyond a point, the model may start to **overfit**.

- **Overfitting**
  - Model is too flexible, captures noise instead of signal.
  - Training error ↓ but test error ↑.

- **Underfitting**
  - Model is too simple, cannot capture the true pattern.
  - Both training and test errors are high.

- **Goal**
  - Find a complexity level that **balances bias and variance**, minimizing test/generalization error.

## 4.6 Sparse Regression

### 4.6.1 Problems with OLS

- **Low Bias, High Variance**
  - OLS tries to fit training data very closely.
  - With many correlated predictors or small sample size, estimates can be highly unstable:
    - Small changes in data → big changes in coefficients.

- **Interpretation Difficulties**
  - When you have many predictors, the model becomes hard to interpret.
  - You may want a simpler model that uses **only a subset** of predictors.

- **Idea**
  - If we allow some coefficients to be **shrunk towards zero** or exactly zero, we can:
    - Reduce variance,
    - Improve prediction on new data,
    - Gain interpretability.

- **Two Main Approaches**
  - **Subset selection**
  - **Regularization (penalty methods)**

---

## 4.7 Subset Selection

### 4.7.1 Objective

- **Goal**
  - Find a **parsimonious** model:
    - Simple, uses fewer predictors,
    - But still explains most of the important variation in y.

- **Benefits**
  - Improved robustness and better prediction on new data (less overfitting).
  - Easier to interpret: focus on a small set of important variables.
  - Consistent with Occam’s Razor:
    - Prefer simpler models when performance is similar.

---

### 4.7.2 Methods

#### (a) Forward Stepwise Selection

- **Procedure**
  - Start with model containing **only the intercept** (no predictors).
  - At each step:
    - Add the predictor that most improves some criterion (e.g., AIC, BIC, adjusted \(R^2\), validation error).
  - Stop when adding more predictors does not significantly improve the model.

- **Pros / Cons**
  - Pros: computationally cheaper than trying all possible subsets.
  - Cons: may miss the globally optimal subset because it adds one variable at a time.

---

#### (b) Backward Stepwise Selection

- **Procedure**
  - Start with the **full model** containing all predictors.
  - At each step:
    - Remove the **least useful** predictor according to some criterion.
  - Stop when removing more predictors hurts model quality too much.

- **Requirements**
  - Need enough data to safely fit the full model initially.
  - When the number of predictors is very large relative to sample size, backward methods can be problematic.

## 4.8 Regularization

*(Section labeled as “9. Regularization” in your notes)*

### 4.8.1 Concept

- **Goal**
  - Control model complexity by adding a **penalty** on large coefficients.
  - Avoid overfitting and improve generalization.

- **Regularized Objective**
  - Minimize:
    \[
      \text{Total Error} + C \times \text{Penalty}(\beta)
    \]
  - \(C\) (or \(\lambda\)) controls the **strength of regularization**.

- **Effect**
  - Larger penalty → coefficients shrink more toward zero.
  - Reduces variance, but may increase bias slightly.

---

### 4.8.2 Lasso (L1 Regularization)

- **Objective**
  - \[
      \min_{\beta} \left[ SSE + C \sum_j |\beta_j| \right]
    \]
- **Key Property**
  - Encourages **sparsity**:
    - Some coefficients are driven exactly to **zero**.
    - Effectively performs **variable selection**.

- **Interpretation**
  - Good when you expect that **only a subset** of predictors are truly important.
  - Resulting model is simpler and easier to interpret.

---

### 4.8.3 Ridge (L2 Regularization)

- **Objective**
  - \[
      \min_{\beta} \left[ SSE + C \sum_j \beta_j^2 \right]
    \]
- **Key Property**
  - Shrinks coefficients towards zero but **rarely makes them exactly zero**.
  - Useful when many predictors have small but non-zero effects.

- **Interpretation**
  - Particularly helpful when predictors are **highly correlated**:
    - Stabilizes coefficient estimates.
    - Reduces variance and improves predictive performance.

---

### 4.8.4 Choosing the Penalty Strength (C)

- **Trade-off**
  - Large C (strong penalty):
    - Coefficients heavily shrunk,
    - Simpler model, higher bias, lower variance.
  - Small C (weak penalty):
    - Model closer to OLS,
    - Lower bias, higher variance.

- **How to Choose**
  - Typically via **cross-validation**:
    - Try a grid of C values,
    - Select the one that minimizes validation error.

## 4.9 Interpretation of Regression Results

### 4.9.1 Typical Steps

- **Step 1: Check Full Model Results**
  - Look at overall fit (e.g., \(R^2\), adjusted \(R^2\)).
  - Inspect residual plots to see if model assumptions are roughly satisfied.
  - Check if there are outliers or influential points.

- **Step 2: Check Test Error**
  - Evaluate MSE, RMSE, MAE, or MAPE on the **test set**.
  - A model that looks great on training data but poor on test data is likely overfitting.

- **Step 3: Compare Coefficients**
  - Examine the **sign** (positive/negative) and **magnitude** of \(\beta_j\).
  - Larger \(|\beta_j|\) often indicates a stronger effect on the dependent variable.

---

### 4.9.2 Normalization for Meaningful Comparison

- **Why Normalize?**
  - If predictors are on very different scales (e.g., years vs. income vs. number of clicks), their coefficients are **not directly comparable**.
  - A variable with a small scale can have a large coefficient and vice versa.

- **Normalization Process**
  - Standardize each predictor:
    - e.g., subtract mean and divide by standard deviation.
  - Fit the regression on these standardized variables.

- **After Normalization**
  - Coefficients represent the effect of a **1 standard deviation** change in each predictor.
  - This makes it more meaningful to compare \(|\beta_j|\) across variables and identify the most influential predictors.
