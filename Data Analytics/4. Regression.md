# 1. Linear Regression

## ■ Multiple Linear Regression
- Assumes linear relationship between response variable (y) and multiple predictors (x)
- y = α + β₁x₁ + β₂x₂ + ... + βᵢxᵢ
- Response variable = dependent variable  
- Predictors = independent/explanatory variables

## ■ Explanatory vs Predictive Regression
### □ Explanatory Regression
- Goal: understand relationships among variables
- Evaluation: R², residual analysis, p-values
- Application: statistical inference

### □ Predictive Regression
- Goal: maximize accuracy on unseen data
- Evaluation: MSE, RMSE, etc.
- Application: prediction in data mining context

- Notations:
  - True value: y
  - Predicted value: ŷ
  - Residual: ε
- Residual = y − f(x)

# 3. Linear Model

## ■ Linear Model Definition
- f(x) = β₀ + β₁x₁ + ... + βₚxₚ
- Vector form: f(x) = β · x
- Residual: ε = y − f(x)

---

# 4. Training Linear Regression Model

## ■ Training Objective
- Find optimal β using training dataset D = {(x₁, y₁), …, (xₙ, yₙ)}

## ■ Ordinary Least Squares (OLS)
- Minimize **sum of squared errors (SSE)**
- SSE = Σ(yᵢ − ŷᵢ)²
- For one predictor:
  - β₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²
  - β₀ = ȳ − β₁x̄

---

# 5. Regression Performance Evaluation

## ■ Training/Test Split
- Training set: model fitting
- Test set: model evaluation
- Do **not** use test set during training

## ■ Error Types
### □ Training error  
Errors evaluated using training data  
### □ Test error  
Errors evaluated using test data  
### □ Generalization error  
Expected error on new samples

## ■ Error Metrics
### □ MSE  
MSE = (1/n) Σ eᵢ²  
### □ RMSE  
RMSE = √MSE  
### □ MAE  
MAE = (1/n) Σ |eᵢ|  
### □ MAPE  
MAPE = (100/n) Σ |eᵢ / yᵢ|

## ■ Goodness of Fit (R²)
- SST = SSR + SSE
- R² = 1 − SSE/SST
- Larger R² → better fit

## ■ Model Complexity
- More complex ≠ better
- Overfitting increases test error  
- Underfitting = overly simple model

# 6. Sparse Regression

## ■ Problems with OLS
- Low bias, high variance  
- Shrinking/zeroing coefficients can improve accuracy  
- Solutions:
  - Subset selection  
  - Regularization  

---

# 7. Subset Selection

## ■ Objective
- Find a parsimonious (simple but effective) model  
- Improves robustness and prediction accuracy  
- Concept: Occam’s Razor

## ■ Methods
### □ Forward Stepwise Selection
- Start with intercept  
- Add predictors sequentially  

### □ Backward Stepwise Selection
- Start with full model  
- Remove least impactful predictors  

---

# 9. Regularization

## ■ Concept
- Penalize large β values to reduce variance and prevent overfitting
- Objective:
  minimize (Total Error + C × Penalty(β))

## ■ Lasso (L1)
- Minimize: SSE + C Σ|βⱼ|
- Encourages **sparse coefficients**  
- Can set some β to zero

## ■ Ridge (L2)
- Minimize: SSE + C Σβⱼ²
- Shrinks coefficients but does not zero them

## ■ Choosing C
- Larger C → stronger penalty  
- Controls trade-off between bias and variance  

---

# 9. Interpretation of Regression Results

## ■ Steps
### □ 1. Check full model results  
### □ 2. Check test error  
### □ 3. Compare coefficients  
- Larger |β| → greater effect on dependent variable  
- Only valid when data is normalized  
- Normalize data, then re-fit for meaningful comparison
